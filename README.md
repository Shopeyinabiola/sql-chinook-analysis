# SQL Analysis: Chinook Music Store

Analysis of the Chinook sample database (a digital music store with 3,500+ tracks, 59 customers and 412 invoices) using MySQL.

## Skills demonstrated
- Joins (inner, left, anti)
- CTEs and recursive CTEs
- Window functions (RANK, ROW_NUMBER, running totals, LAG/LEAD)
- Views, subqueries and indexes

## Tools
MySQL Workbench, MySQL 8

## Dataset
Chinook sample database by Luis Rocha (MIT licence): https://github.com/lerocha/chinook-database
